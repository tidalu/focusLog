# Phase 4 Hardening Backlog

These items are intentionally outside the Phase 4-A release-critical slice because persistent isolation, provider-backed chat, streaming cancellation, restart reconciliation, branching operations, policy gates, and secret-safe projections have representative executable coverage.

## Phase 4-A

- Long-session soak and extreme message branching.
- Additional provider-specific streaming edge cases beyond the deterministic cancellation/late-completion fixture.
- Advanced collaborative or shared-session concepts.

## Phase 4-B

- Visual prompt-diff enhancements beyond deterministic field-level diffing.
- Additional automatic context-building strategies.
- Model-based prompt quality recommendations.

## Phase 4-C

- Advanced statistical model comparison beyond deterministic checks and user ratings.
- Visualization of full vectors beyond sampled safe inspection/export.
- Experimental learned retrieval tuning beyond deterministic inspector traces.

## Phase 4-D

- Additional quality metrics beyond the deterministic release matrix.
- Large external benchmark corpora.
- Automated prompt optimization.

## Phase 4-E

- Long-running chat/comparison soak.
- Additional external evaluation formats.
- Advanced visualization and prompt-optimization experiments.
